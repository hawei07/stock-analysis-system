# PE-TTM 估值计算四轮演进

## 数据流

```
东方财富 API (PARENTNETPROFIT + TOTAL_SHARE)
  → TTM EPS = 归母净利润 / 总股本
  → PE = 前复权股价 / TTM EPS
  → ECharts 渲染
```

## Round 1: 年报 EPS（❌ 错误）

```
PE = close_price / latest_annual_EPS
```

**问题**: 2026年7月仍用2024年报EPS，导致PE=12.81 vs 腾讯实时8.96。

## Round 2: TTM 滚动（✅ 方向正确但缺披露延迟）

```
TTM_EPS = 最新年报EPS - 去年同期累计EPS + 今年最新累计EPS
PE = close_price / TTM_EPS
```

拉取四种报告类型（年报/一季报/半年报/三季报），日级别TTM计算。

**问题**: 2025-09-30直接用了三季报EPS，但三季报实际10月底才披露，导致PE从~15突降到~14。

## Round 3: 披露延迟（✅ 正确）

| 报告类型 | 财季截止 | 法定披露截止 | 生效日 |
|---------|---------|------------|-------|
| 年报 | 12-31 | 次年4-30 | 5-1 |
| 一季报 | 3-31 | 4-30 | 5-1 |
| 半年报 | 6-30 | 8-31 | 9-1 |
| 三季报 | 9-30 | 10-31 | 11-1 |

2025-09-30 PE 修正为 16.38（接近外部网站 15.33）。

## Round 4: 归母净利润/总股本（✅ 当前，最精确）

```
PE = 市值 / (期末归母净利润 + 期初全年归母净利润 - 期初归母净利润)
```

即：`PE = 股价 / (PARENTNETPROFIT / TOTAL_SHARE)`

**为何比 EPSJB 更精确**:
- EPSJB — 公司自行披露的加权平均EPS，含股本变动加权、四舍五入
- PARENTNETPROFIT/TOTAL_SHARE — 原始数据直接计算，每期独立获取TOTAL_SHARE

**结果**: 最新 PE = 8.96，与腾讯实时 PE-TTM 完全一致。
